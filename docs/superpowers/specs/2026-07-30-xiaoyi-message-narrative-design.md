# 小易编排消息客户化展示设计

## 目标

将小易工具接口返回体内嵌套的 `message`、`name`、`status`、`timestamp` 提取为客户可理解的编排步骤。默认界面不再直接铺开 JSON；原始结果仅作为折叠的技术详情保留。

## 展示规则

- 每条消息展示执行主体、当前动作、动作目的、状态与时间。
- 根据 WebRE、API Fuzzer、信息收集、漏洞验证、报告生成等已知角色补充一句稳定、非夸大的通俗解释。
- 未识别角色保留小易原始 `message`，使用通用说明，不臆造工具能力或扫描结论。
- 等待消息明确说明依赖关系；完成消息说明已产出什么以及下一步；失败消息保留失败原因。
- 对嵌套对象和数组递归提取消息，并按主体、消息、时间去重。
- 敏感键继续脱敏。完整结果摘要放入“查看技术详情”折叠区。

## 数据流

`小易 tools 响应 → JSON 安全解析与脱敏 → 递归提取消息 → 角色解释与状态归一化 → 时间线客户卡片 → 折叠技术详情`

## 验收

- 截图中的 `等待 WebRE工具 产出 API 线索后执行`、`执行 WebRE工具` 等消息能成为独立说明步骤。
- 默认页面不出现整块原始 JSON。
- 不包含 `message` 的旧工具结果仍显示原有工具状态。
- 单元测试覆盖递归、去重、解释、脱敏和失败结果。
