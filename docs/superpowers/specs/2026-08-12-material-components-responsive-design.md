# 素材组件与响应式页面设计

## 目标

以 `素材/AI安服平台` 中最新整页 SVG 和 `组件*.svg` 为唯一视觉依据，更新渗透测试之外的功能页面组件，并让页面在 1366、1440、1920、2560 与 3840 宽度下保持相同的信息层级、合理密度且不发生横向溢出或文字挤压。

## 素材映射

- `组件.svg`：平台总览；`组件-1.svg`：任务中心；`组件-2.svg`：登录。
- `组件-3.svg`：系统设置；`组件-4.svg`：团队管理；`组件-14.svg`：授权管理。
- `组件-5.svg`：漏洞总览；`组件-6.svg`：漏洞列表；`组件-7.svg`、`组件-8.svg`：漏洞详情。
- `组件-9.svg`：报告总览；`组件-10.svg`：报告列表。
- `组件-11.svg`、`组件-12.svg`、`组件-13.svg` 属于渗透测试流程，本轮不修改。

## 组件实现

继续复用现有 React、Ant Design、CSS Variables 和项目已有图标素材。按钮、标签、指标卡、筛选栏、列表状态、图表和管理页控件按对应组件 SVG 的颜色、尺寸、圆角、层级和状态组合实现；不新增没有素材依据的装饰、卡片或交互。

整页 SVG 用于校对页面编排，组件 SVG 用于校对控件细节。真实接口数据、加载态、空态和错误态保持现有契约，不用素材中的演示数字覆盖真实数据。

## 响应式策略

- 不对根节点使用 `transform: scale()`、`zoom` 或 1920px 固定画布。
- 外壳使用流式侧栏、标题栏和内容留白；内容区使用 `minmax(0, 1fr)`、`clamp()` 和容器最大宽度。
- 1366/1440 宽度收紧间距并允许指标和图表按素材顺序换行；1920 宽度还原设计稿比例；2K/4K 增大可读尺寸但限制内容行宽，避免无限拉伸。
- 表格在必要时仅自身横向滚动，页面根节点不得横向滚动；长文本用省略或正常换行，禁止逐字竖排。
- 登录页改为流式最小宽度，表单卡在各桌面宽度保持完整。

## 验证

组件结构先由 Vitest 约束；响应式 CSS 规则先用回归测试约束。实现后运行前端单测、lint、build，并用 Playwright 在 1366×768、1440×900、1920×1080、2560×1440、3840×2160 截取关键页面，检查页面宽度、文本折行、组件重叠和素材一致性。
