# 浏览器原生等比缩放设计

## 目标

桌面浏览器放大或缩小时，平台保持侧栏、主内容区、专家咨询区和装饰素材的既有相对布局，由浏览器统一缩放文字、按钮、图片和弹窗。

## 已确认行为

- 使用浏览器原生缩放，不使用 CSS `transform` 或脚本模拟缩放。
- 桌面设计画布最低宽度为 1280px。
- 视口不足 1280px 时允许横向滚动，不再自动压缩侧栏、缩窄专家区或隐藏人物图。
- 窗口变窄与浏览器放大采用相同行为，因为浏览器没有可靠的标准接口区分二者。
- 不修改业务组件、接口、素材或依赖。

## 实现

- 将 `html`、`body` 和 `#root` 的最小宽度设为 1280px。
- 删除会随视口宽度改变全局布局的 1600px、1440px、1439px 和 1050px 媒体查询。
- 保留长 URL、资产标签、咨询消息和弹窗按钮的换行保护，避免单个内容继续撑宽画布。
- 保留授权弹窗的视口安全宽度；其常规宽度仍为 720px。

## 验收

- 1920px 下侧栏为 260px、专家区为 352px、人物图可见。
- 1280px 下上述三项保持不变。
- 1024px 视口下文档宽度保持至少 1280px并产生横向滚动，核心布局不重排。
- 单元测试、完整 Playwright 流程、ESLint、TypeScript 和生产构建通过。

## 非目标

- 不提供应用内缩放按钮。
- 不实现手机或平板专用布局。
- 不尝试抵消操作系统 DPI 缩放。
