# 非阻塞任务信息补充对话设计

## 目标

删除渗透测试页面中的所有右侧“专家咨询区”。用户完成平台要求的 CDN/资产检测和授权确认、点击“创建任务”后，任务立即启动；任务执行页中央底部的现有对话框再主动询问可选的补充信息，用户是否回复都不阻塞任务执行。

## 范围

- 删除新建任务页的右侧专家咨询栏、相关双栏布局和专用组件。
- 保留现有目标录入、需求分析、CDN/WAF 检测、资产预查和授权确认流程。
- 保留任务执行页中央时间线和底部悬浮对话框。
- 正式任务创建成功后，在当前任务的对话记录中加入一条补充信息提示。
- 用户通过底部对话框回复时，继续调用现有任务问答接口，并关联当前任务。
- 补充信息只用于丰富小易会话上下文，不改变任务状态，不暂停、不排队、不重新创建任务。

不在本次范围内：新增后端接口、修改小易协议、改变 CDN 阻断规则、增加依赖或重构任务执行架构。

## 交互流程

1. 用户在“新建渗透测试”页输入目标并开始分析。
2. 平台创建扫描计划，完成现有需求分析、资产/CDN 预查和授权确认。
3. 用户点击“创建任务”，平台立即创建并启动正式任务，然后进入该任务的执行页。
4. 执行页底部对话框自动显示一条非阻塞提示，询问白盒账号、特殊入口、测试限制、业务窗口等补充信息。
5. 用户可以立即回复、稍后回复或完全忽略；任务进度和小易回传持续刷新。
6. 用户回复与小易响应继续显示在中央统一时间线中，不恢复任何右侧咨询区域。

## 组件与数据流

### 新建任务页

`PentestPage` 仍负责创建计划、预检、授权和创建任务，但不再保存或渲染专家咨询栏的消息状态。计划创建后的需求分析结果保留在当前方案确认区域中，避免丢失已有反馈。

### 任务执行页

`PentestSessionPage` 继续使用 `TaskConversation`。任务首次进入执行页时，如果任务问答历史中尚无补充提示，则由前端展示固定的引导语；不为展示该提示额外写入后端，也不重复发送给小易。

用户主动提交的内容仍通过现有 `createTaskQAMessage` 接口发送。收到的任务问答和小易回传按当前刷新机制进入统一时间线。

### 删除内容

- 删除 `ExpertFeedbackPanel` 组件及其专用测试。
- 删除 `PentestPage` 中仅服务于右侧咨询栏的状态、发送逻辑和导入。
- 删除不再被引用的专家咨询栏和双栏布局样式。

## 状态与错误处理

- 任务创建成功后立即导航，不等待补充信息。
- 对话发送失败时沿用执行页现有错误提示，不影响任务轮询与回传展示。
- 任务历史为空时仅展示一次本地引导语；已有历史时直接展示真实会话，避免重复询问。
- CDN/WAF 不安全、资产未知或授权未确认时，仍禁止创建任务。

## 验收标准

- 新建任务页和任务执行页均不存在名为“专家咨询区”的侧栏。
- 新建任务页不再为侧栏预留宽度，主内容使用完整可用宽度。
- 点击“创建任务”后任务正常启动并跳转，不因补充信息而等待。
- 新任务执行页底部对话框显示补充信息提示。
- 用户不回复时，任务状态、工具事件、漏洞和小易回传仍持续更新。
- 用户回复时，内容正确关联当前任务并显示在中央时间线。
- 现有 CDN 检测、资产预查和授权确认测试继续通过。
- 前端单元测试、类型检查、Lint 和生产构建全部通过。
