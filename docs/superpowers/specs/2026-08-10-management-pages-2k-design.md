# 管理页面与 2K 桌面适配设计

## 目标

依据 `素材/登录、系统设置、团队、授权.zip` 中的新增设计切片，更新登录、平台设置、团队管理和授权审计页面，并让现有站点在 2560×1440 及更高桌面分辨率下保持清晰、舒展且不被无限拉宽。

## 范围

- 重做登录页视觉，但保留现有登录接口、登录后回跳和错误提示。
- 将平台设置页改为素材中的顶部状态、分区卡片和统一表单风格，数据来自现有组织配置与运行配置接口。
- 新增团队管理页，使用现有用户列表、创建用户和更新用户接口。
- 新增授权与审计页，使用现有组织信息、运行状态和审计日志接口；不新造授权服务或后端协议。
- 在侧边栏的平台设置下增加“系统设置、团队管理、授权管理”入口。
- 建立统一的超宽桌面布局变量。1920px 保持当前密度；2560px 及以上增加内容宽度、间距和卡片列宽，但正文与表格设置最大宽度，避免内容被横向摊薄。
- 不调整代理、小易、扫描任务、回传和报告接口。

## 方案选择

### 方案 A：直接把 PNG 切片作为控件背景

还原最快，但按钮文字和状态被固化，缩放时容易失真，也不利于无障碍和交互状态。仅适合纯展示稿，不采用。

### 方案 B：用现有 React、Ant Design 与 CSS 复刻素材（采用）

保留真实组件和接口行为，只把素材作为视觉基准。优点是 2K 缩放稳定、交互状态完整、无需新增依赖；代价是需要统一整理样式变量和页面组件。

### 方案 C：只更新登录和现有设置页

改动较小，但浪费团队与授权素材，也无法利用已有管理接口，不采用。

## 页面结构

### 登录页

- 全屏浅蓝背景与居中的品牌区。
- 白色圆角登录面板，输入框和主按钮按素材的浅灰填充、蓝色描边与柔和阴影实现。
- 继续显示服务端错误、加载态、密码显隐和原目标路由回跳。

### 管理页公共壳

- 平台设置导航作为父菜单，下设系统设置、团队管理和授权管理。
- 页面使用统一标题区、状态说明、操作区与白色内容卡片。
- 管理页面共享 `ManagementPageHeader`，避免每页重复结构。

### 系统设置

- 基础信息：组织名称，可由管理员保存。
- 运行状态：应用名称、引擎模式、引擎是否配置、同步间隔、重试次数和报告存储方式，只读显示服务端真实值。
- 安全说明：明确凭据仅由服务端配置，页面不展示或保存密钥。

### 团队管理

- 顶部统计成员总数、启用数、数字人账号数。
- 成员表格展示姓名、账号、角色、账号类型和状态。
- 管理员可添加成员、调整角色和启停账号；当前管理员的自锁限制交给现有后端校验并显示错误。

### 授权与审计

- 展示组织标识、运行配置和安全边界摘要。
- 审计日志按时间倒序显示操作人、动作、资源、结果和时间。
- 提供动作与资源类型筛选、刷新和分页；不实现素材中没有后端契约支持的许可证上传或下载。

## 数据流与错误处理

- 所有管理数据继续通过统一 `apiRequest` 客户端访问 `/api/v1/*`。
- 使用 TanStack Query 管理列表、详情与失效刷新；表单使用现有 React Hook Form/Zod 约束。
- 401 继续走现有登录态处理；403 显示权限提示；409 显示服务端冲突原因；加载失败保留可见的重试入口。
- 非管理员访问团队写操作时隐藏或禁用操作，但仍以服务端权限校验为准。

## 2K 与更高分辨率策略

- 保持浏览器原生缩放，不使用 `transform: scale()` 或页面级 `zoom`。
- 使用 `--shell-sidebar-width`、`--content-max-width`、`--page-gutter` 等 CSS 变量控制全站尺度。
- 默认桌面最大内容宽度约 1600px；在 2560px 及以上提升到约 2100px，并增加页面边距和网格间隔。
- 登录卡片、表格、任务时间线和对话区保持可读行宽；空余空间用于边距和列间距，而不是拉伸文字。
- 本期不为窄屏重排，与用户确认的单一桌面浏览器版保持一致。

## 验证标准

- 登录、系统设置、团队管理、授权管理路由均可直接访问且刷新不丢失。
- 管理页真实调用现有后端接口，新增/更新成员和组织名称后可重新查询到结果。
- 1920×1080、2560×1440、3840×2160 下无横向遮挡、重叠或被无限拉伸的卡片。
- 原有渗透测试、任务、漏洞和报告页面行为不变。
- 前端相关单元测试、完整测试、lint 与生产构建通过。
