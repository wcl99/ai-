# 桌面任务页布局优化设计

## 目标

针对当前桌面浏览器任务执行页，改善左侧任务概览的可读性、漏洞等级标签的位置，以及执行时间线展开入口的遮挡问题。

## 范围

- 仅调整桌面浏览器布局，不新增窄屏或移动端适配。
- 左侧任务概览列固定拓宽为 `320px`。
- 漏洞等级标签移动到漏洞名称末尾，与名称处于同一个标题区域。
- 执行时间线的展开入口使用独立固定列，不与统计信息或进度条重叠。
- 保留现有任务、漏洞、报告和工具调用数据结构。
- 不新增依赖，不修改后端接口、小易协议或项目代理配置。

Codex 后续操作继续使用已验证成功的访问与部署路径；该约定不写入项目运行逻辑。

## 布局设计

### 左侧任务概览

`execution-workbench--conversation` 的任务栏列宽从 `250px` 调整为 `320px`。任务卡片继续使用现有纵向列表，但标题区域允许名称自然换行，避免单词级挤压。

漏洞卡片标题调整为一个可换行的行内标题组：漏洞名称在前，等级标签紧随名称末尾。标签保持内容宽度且不收缩，不再作为独立右侧列。漏洞资产地址继续独占下一行。

报告卡片和子任务卡片保持现有数据与状态展示，仅共享拓宽后的空间。

### 执行时间线

阶段摘要固定为四个区域：

1. 阶段名称和时间；
2. 调用次数、工具数量和失败次数；
3. 进度条和百分比；
4. 展开/收起入口。

最后一个区域使用独立固定宽度并右对齐。展开状态文案随 `<details>` 状态变化，整行仍可点击，同时确保入口不会覆盖进度或统计标签。

工具调用摘要同样将状态标签与“查看调用”归入右侧操作组，名称区域保持最小可缩宽度。只使用现有 HTML `<details>/<summary>` 和 CSS Grid。

## 状态与可访问性

- 折叠状态显示“展开详情”或“查看调用”。
- 展开状态显示“收起详情”或“收起调用”。
- 保留原生 `<details>` 键盘操作能力。
- 等级标签文本、颜色与现有数据保持一致。
- 不截断漏洞名称，不通过悬浮提示隐藏关键信息。

## 验收标准

- 桌面任务栏宽度为 `320px`，漏洞名称不再被压成窄列。
- 严重、中危、低危等标签位于对应漏洞名称末尾。
- 标签不被压缩，资产地址保持在标题下方。
- 时间线阶段摘要的展开入口位于最右独立区域。
- 工具摘要的“查看调用”不遮挡名称、计数或状态。
- 展开/收起状态文案正确更新。
- 现有任务查询、漏洞查询和对话功能不受影响。
- 前端测试、ESLint、TypeScript 和生产构建全部通过。
