# AI 安服平台素材对齐设计

## 目标

以 `素材/AI安服平台` 中的整页 SVG、设计规范和组件素材为唯一视觉基准，改造现有平台中除渗透测试流程外的页面，使 1920×1080、2K 及更高分辨率下的结构、比例、色彩和信息密度尽量贴近素材，同时保留现有真实 API、权限和业务行为。

## 保护范围

以下页面与其组件、数据流、样式选择器不修改：

- `/pentest`
- `/pentest/session/:sessionId`
- 新建渗透任务、预查、CDN 检测、授权、任务执行时间线和任务会话

全局外壳的改动必须通过路由级样式隔离，不能改变上述页面的宽度计算、固定对话框或执行时间线布局。

## 视觉系统

- 使用素材定义的主色 `#014AC6`、浅蓝灰工作区、白色卡片、红色风险色和紫/绿/橙辅助色。
- 保留 Ant Design 与 `@ant-design/icons`，图表继续使用现有 CSS/SVG 实现，不新增图表库。
- 页面采用稳定桌面画布：侧栏约 260px、顶栏约 64px、内容区最小宽度保证表格与图表不被挤压；大屏增加留白而非无上限拉伸。
- 数据不可用时显示真实空状态，不以素材演示数字伪造业务数据。
- 素材中的按钮只有在现有 API 支持时启用；未实现接口的动作保持禁用并明确原因。

## 页面结构

- 总览页按素材组织指标卡、四个工作台、AI 摘要、趋势与分布、近期任务、最新动态和快捷入口。
- 列表页统一为指标卡、筛选工具栏、业务表格和分页；漏洞详情使用右侧抽屉复刻素材信息层次。
- 报告页保留已完成的真实统计接口和时间颗粒度，只调整至素材布局。
- 设置、团队、授权页以素材为准；授权管理继续只做展示，不新增未确认的授权后端能力。
- 登录页改为素材的居中品牌、居中登录卡和验证码结构，但仍使用现有登录接口。

## 验证

- Vitest：页面标题、指标、筛选、详情抽屉、设置页签和保护路由结构。
- ESLint、TypeScript/Vite build。
- Playwright：桌面主流尺寸与 2560×1440 截图检查；验证无横向挤压、遮挡和资源缺失。
- 对渗透测试相关测试执行回归，确保保护区未改变。
