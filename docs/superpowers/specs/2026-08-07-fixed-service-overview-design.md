# 固定服务概述章节设计

## 目标

生成报告的“服务概述”章节必须逐字采用参考文件 `渗透测试报告.md` 第 109 至 223 行的内容，不再根据任务子任务或工具回传动态生成。

## 边界

- 仅修改现有 Markdown 报告模板和对应渲染测试。
- “服务结果”“漏洞描述”“风险评级”“漏洞评级”继续使用当前动态数据。
- 保持现有 Markdown -> DOCX -> PDF 离线转换链路、接口和数据库结构不变。
- 不新增依赖、服务或配置。

## 验收

- 服务概述包含参考文档中的测试人员、测试目的、测试流程、测试工具和测试依据原文。
- 子任务名和工具名不会进入服务概述。
- 后端测试通过；平台报告接口可列出并下载生成文件；测试 DOCX/PDF 视觉检查无截断、重叠或乱码。
