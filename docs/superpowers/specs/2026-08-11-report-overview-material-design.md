# 报告总览素材复刻与生命周期统计设计

## 目标

严格以 `素材/报告总览.svg` 为最高优先级视觉权威来源，以此前的报告总览 JPG 和用户最新补充的按钮、图标、装饰素材作为辅助对照，重做报告总览。页面结构、比例、信息层级、配色和图表表现与 SVG 一致，同时保证所有数字均来自平台真实数据，不使用素材中的演示数字。

本次改动保持现有 React SPA、FastAPI 模块化单体和 PostgreSQL 架构。不增加依赖，不引入缓存、微服务、任务队列或新的状态管理方案。

## 报告生命周期与统计口径

报告生成后默认处于“未查看、未导出”状态。平台记录首次成功查看和首次成功导出，不按重复操作累计报告数。

- `first_viewed_at`：首次成功打开预览或首次成功下载的时间。
- `first_viewed_by`：触发首次查看的用户。
- `first_exported_at`：首次成功下载的时间。
- `first_exported_by`：触发首次下载的用户。
- 直接下载同时视为查看，因此会在必要时同时写入首次查看和首次导出字段。
- 只有文件存在、内容读取或下载响应可以正常生成时才更新状态；失败请求不得改变统计。

六项顶部指标按当前组织统计：

1. 报告总数：全部报告数。
2. 本月新增：客户时区本月生成的报告数。
3. 待导出：`first_exported_at IS NULL`。
4. 已导出：`first_exported_at IS NOT NULL`。
5. 待确认：`first_viewed_at IS NULL`，含义是报告生成后尚无人查看。
6. 本月交付：客户时区本月首次被预览或下载的报告数。

指标对比值不使用模拟比例。全量和状态指标与客户时区前一自然日结束时的可重建快照比较；本月新增和本月交付与上月同期比较。基线为零时返回不可计算状态，前端显示“暂无对比”，不显示虚假百分比。

## 分类与趋势

### 来源分布

按照报告关联扫描计划的业务类型归类：

- 渗透测试
- 代码审计
- 应急响应
- 数据分析

当前尚未启用的业务类型返回零值并保留在图例中。未知类型归入“其他”，避免丢失数据。

### 风险等级分布

按照报告关联任务内已确认漏洞的最高严重度分类：严重、高危、中危、低危。没有已确认漏洞的报告不伪装成低危，在图表旁以“无已确认风险”单独列示。

### 生成趋势

保留已确认的四档范围：

- 当日：客户时区当日 00:00 至当前小时，按小时。
- 3日：最近 72 个小时，按小时。
- 7日：最近 7 个自然日，按日。
- 历史：不足 90 天按日，否则按月。

时间范围控件放在趋势卡标题右侧，不单独占据页面一行。过滤边界继续使用 UTC 左闭右开区间，返回数据按客户时区分桶并补零。

## 页面布局

页面针对当前桌面浏览器和 2K 以上分辨率实现，沿用平台侧边栏与顶部栏，内容区严格复刻素材的四层结构。

### 第一层：六项指标

六张等宽卡片，统一高度。左侧显示名称、主数字和真实对比信息；右侧使用素材目录中的淡色水印图形。加载态保持相同尺寸，错误态在卡片内提供局部重试。

### 第二层：三张图表卡

- 左侧为报告来源粗圆环，中心显示报告总数，右侧显示分类色点、名称和数量。
- 中间为报告生成柱状图，标题右侧放置四档范围选择，提供坐标轴和悬浮提示。
- 右侧为风险等级粗圆环，中心显示风险报告总数，右侧显示各等级数量，并展示无已确认风险数。

三张卡片宽度、高度、内边距和标题位置与素材对齐。

### 第三层：最近新增报告

横向展示五张报告卡。每张卡包含来源标签、日期、报告名称、创建人头像和姓名。右侧复用素材中的前进按钮；“查看全部”进入报告列表。

### 第四层：最近导出与报告洞察

- 左侧约占一半宽度，显示最近导出的报告表格：报告名称、来源、格式、导出人、状态、导出时间。
- 右侧约占一半宽度，显示报告洞察：顶部真实摘要框，下方列出确定性建议。洞察由聚合数据生成，不调用模型补造结论。

## 图表实现

使用原生 SVG 实现环图和柱图，不新增图表依赖。图形使用 `viewBox` 自适应容器，数据点用原生 `title` 与屏幕阅读器文本提供精确信息。

环图使用素材中的色阶、圆环厚度、中心双层文字和右侧图例；柱图使用蓝色圆角柱、浅色网格线、紧凑坐标标签和真实悬浮提示。动画只用于首次呈现和范围切换，不持续占用资源。

## 素材使用规则

- `素材/报告总览.svg` 是最终布局与视觉验收基准；其画布为 `1920×1080`，实现与截图验收均以该桌面比例为准。
- SVG 内含 200 个矩形、214 条矢量路径、21 个线性渐变、49 个滤镜和 5 个内嵌图像，足以作为卡片轮廓、装饰水印、按钮、图标、渐变和阴影的精确测量来源。
- SVG 文字已转为路径，不把整张 SVG 当作页面背景，也不从路径反推业务文案；文案继续使用可访问、可搜索、可缩放的 HTML 文本，并按 SVG 中的字号、字重、行高和位置测量值实现。
- 此前的 JPG 只作为渲染兼容性与肉眼对照备份；SVG 与 JPG 不一致时以 SVG 为准。
- 实施前盘点用户最新更新的按钮、图标和装饰文件，复制需要的资源到 `apps/web/public/ui-icons`，使用稳定的英文文件名。
- 能复用的独立 SVG 素材直接复用；属于整页 SVG 的图形只拆出确有必要且授权明确的装饰或图标，避免复制整页结构。数据图形本身使用原生 SVG 动态渲染。
- 不提交 macOS 元数据、压缩包副本或未使用素材。

## API 与数据库

新增 Alembic 迁移，为 `reports` 增加四个生命周期字段及组织范围查询需要的索引。用户外键可空，以保留账号删除或历史数据场景。

扩展报告总览响应：

- 六项指标及可空对比值。
- 来源分布、风险等级分布、趋势。
- 最近新增五项、最近导出五项。
- 确定性洞察列表。

报告列表和详情返回首次查看、首次导出摘要字段。预览和下载操作在现有鉴权与组织隔离条件下更新生命周期字段并写入审计日志。

## 错误与安全边界

- 所有统计必须包含 `org_id` 条件。
- 只有成功预览或下载才写入首次时间；事务失败保持原状态。
- 重复预览、重复下载使用条件更新，永不覆盖首次操作人和时间。
- 不暴露本地报告路径，不改变现有报告文件大小、编码和 URL 安全校验。
- 图表接口失败时保留页面结构并提供重试，不把加载失败显示为真实零值。
