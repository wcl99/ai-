# 管理页面素材还原设计

## 目标

以 `素材/系统设置/` 中最新 SVG 为唯一视觉基准，重做系统设置、团队管理和授权管理三个页面。系统设置与团队管理提供当前后端能力允许的真实操作；授权管理本期只完成视觉展示，不新增许可证服务、接口或依赖。

## 方案选择

采用“素材精准还原 + 现有接口复用”的方案：继续使用当前 React、Ant Design、TanStack Query 与现有 API 客户端，通过页面组件和 CSS 还原素材，不把整张 SVG 当作页面背景，也不新增图表、表单或状态管理依赖。

不采用纯静态页面方案，因为它会让现有团队成员管理能力退化；不采用全量后端配置方案，因为许可证和多数系统设置尚无已确认接口，本期不得自行创造协议。

## 页面结构

### 系统设置

系统设置页提供五个可切换页签：

1. 认证与安全：登录与退出、审计日志、访问控制三组配置。
2. AI 模型：模型平台、API 地址、API Key、模型名称。
3. 场景配置：最大并发任务数、弱口令默认凭据、弱口令字典和高风险端口。
4. 规则配置：不活跃阈值、最小密码长度、规则开关与 JSON 预览。
5. 模块管理：渗透测试、应急响应、代码审计、数据分析模块开关。

页面严格复刻对应 SVG 的页签、白色卡片、表单密度、开关、表格和底部操作栏。已有组织信息与运行配置继续读取真实接口；素材中没有后端契约的配置仅保存在浏览器本地，并在页面上标识“本地配置”，避免伪装成服务端配置。敏感凭据不回显明文，API Key 使用密码输入框。

### 团队管理

团队管理页按素材分为左侧组织树和右侧成员区：

- 左侧包含组织搜索、当前组织与部门层级；没有组织树接口时，由现有组织信息与成员角色生成稳定的展示分组。
- 右侧包含页面说明、批量导入和新增成员操作、部门与成员数量统计、关键词和状态筛选、成员表格与分页。
- 成员列表、新增成员和启停状态继续使用现有用户接口。
- 批量导入在没有既有接口时保持禁用，并显示“暂未开放”，不模拟成功。

### 授权管理

授权管理页还原系统指纹、许可证状态和许可证上传区域。所有授权相关按钮和拖拽上传均禁用，统一提示“授权管理功能暂未开放”。页面不请求或提交虚构的许可证数据，不新增后端路由。

## 组件与状态边界

- 保留现有 AppShell、路由与请求封装。
- 页面内只抽取确实复用的管理页标题、设置页签和状态卡片；不建立新的通用组件框架。
- 系统设置本地状态使用一个版本化的 `localStorage` 键；读取失败或数据结构不兼容时回退为素材默认值。
- 团队接口失败时显示明确错误与重试入口；写操作成功后失效成员查询并重新加载。
- 禁用操作必须有可见说明，不能出现可点击但无响应的按钮。

## 视觉与分辨率

- 以 1920×1080 素材为基准，页面主体使用固定桌面最小宽度和可增长的内容区。
- 2K 及更高分辨率增加页面留白和卡片可用宽度，但限制表单行宽，避免文字和控件被无限拉伸。
- 不使用页面级 `zoom` 或 `transform: scale()`，避免文本模糊和交互坐标偏移。
- 复用素材中的 SVG 图标和当前项目图标体系；缺失图标只使用已安装图标库，不新增依赖。

## 测试与验收

- 系统设置五个页签均可切换并显示对应素材内容。
- 系统设置本地配置保存后刷新仍可恢复，重置后回到默认值。
- 团队管理真实渲染成员列表，筛选、分页、新增成员和启停成员保持可用。
- 授权管理操作全部不可执行，并显示暂未开放提示。
- 1920×1080、2560×1440 与 3840×2160 下无卡片重叠、横向遮挡或表格内容挤压。
- 管理页面相关单元测试和前端生产构建通过；本期不要求对整个项目执行全量端到端测试。

## 非目标

- 不实现许可证生成、上传、校验、刷新或后端存储。
- 不新增系统设置后端表、接口或微服务。
- 不修改小易、扫描任务、回传、报告生成和代理链路。
- 不为窄屏或移动端设计新的响应式布局。
